# 코드 리뷰 체크리스트

## 보안 체크리스트
- [ ] 하드코딩된 자격 증명이나 비밀 정보가 없음
- [ ] 모든 사용자 입력을 검증함
- [ ] SQL 인젝션 방지 (매개변수화된 쿼리)
- [ ] 상태를 바꾸는 작업에 CSRF 보호 적용
- [ ] 올바른 이스케이프 처리로 XSS 방지
- [ ] 보호된 엔드포인트에서 인증 확인
- [ ] 리소스에 대한 인가 확인
- [ ] 안전한 비밀번호 해싱 (bcrypt, argon2)
- [ ] 로그에 민감한 데이터가 없음
- [ ] HTTPS 강제

## 성능 체크리스트
- [ ] N+1 쿼리가 없음
- [ ] 인덱스를 알맞게 사용
- [ ] 도움이 되는 곳에 캐싱 구현
- [ ] 메인 스레드를 막는 작업이 없음
- [ ] Async/await를 올바르게 사용
- [ ] 큰 데이터셋은 페이지로 나눔
- [ ] 데이터베이스 커넥션 풀 사용
- [ ] 정규 표현식 최적화
- [ ] 불필요한 객체 생성이 없음
- [ ] 메모리 누수 방지

## 품질 체크리스트
- [ ] 함수는 50줄 미만
- [ ] 명확한 변수 이름
- [ ] 중복 코드가 없음
- [ ] 올바른 오류 처리
- [ ] 주석은 '무엇'이 아니라 '왜'를 설명
- [ ] 운영 코드에 console.log가 없음
- [ ] 타입 검사 (TypeScript/JSDoc)
- [ ] SOLID 원칙을 따름
- [ ] 디자인 패턴을 올바르게 적용
- [ ] 그 자체로 설명이 되는 코드

## 테스트 체크리스트
- [ ] 단위 테스트 작성
- [ ] 경계 사례를 다룸
- [ ] 오류 시나리오 테스트
- [ ] 통합 테스트가 있음
- [ ] 커버리지 > 80%
- [ ] 불안정한 테스트가 없음
- [ ] 외부 의존성은 목(mock)으로 대체
- [ ] 명확한 테스트 이름
