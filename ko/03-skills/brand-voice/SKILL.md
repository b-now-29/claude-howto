# 브랜드 보이스 스킬

## 개요
이 스킬은 모든 커뮤니케이션이 일관된 브랜드 보이스, 어조, 메시지를 유지하도록 합니다.

## 브랜드 정체성

### 미션
팀이 AI로 개발 워크플로를 자동화하도록 돕습니다

### 가치
- **단순함**: 복잡한 것을 단순하게
- **신뢰성**: 흔들림 없는 실행
- **역량 강화**: 사람의 창의성을 끌어내기

### 어조
- **친근하지만 전문적으로** - 가볍지 않으면서도 다가가기 쉽게
- **명확하고 간결하게** - 전문 용어를 피하고, 기술 개념은 쉽게 설명하기
- **자신 있게** - 우리는 무엇을 하는지 알고 있다
- **공감하며** - 사용자의 필요와 고충을 이해하기

## 작성 가이드라인

### 해야 할 것 ✅
- 독자에게 직접 말하듯 씁니다 (영어 문서라면 "you"를 씁니다)
- 능동태를 씁니다: "보고서가 Claude에 의해 생성됩니다"가 아니라 "Claude가 보고서를 만듭니다"
- 가치 제안으로 시작합니다
- 구체적인 예시를 씁니다
- 문장은 짧게 씁니다 (영어 기준 20단어 미만)
- 명확하게 전달하려면 목록을 씁니다
- 행동을 이끄는 문구를 넣습니다

### 하지 말아야 할 것 ❌
- 기업식 전문 용어를 쓰지 않습니다
- 깔보거나 지나치게 단순화하지 않습니다
- "저희는 ~라고 믿습니다", "저희 생각에는" 같은 표현을 쓰지 않습니다
- 강조할 때가 아니면 전부 대문자로 쓰지 않습니다
- 글자로 꽉 찬 덩어리를 만들지 않습니다
- 독자가 기술 지식이 있다고 가정하지 않습니다

## 어휘

### ✅ 권장 용어
- Claude ("Claude AI"라고 하지 않음)
- 코드 생성 ("자동 코딩"이라고 하지 않음)
- 에이전트 ("봇"이라고 하지 않음)
- 간소화하다 ("혁명을 일으키다"라고 하지 않음)
- 연동하다 ("시너지를 내다"라고 하지 않음)

### ❌ 피할 용어
- "최첨단" (남용됨)
- "게임 체인저" (막연함)
- "레버리지하다" (기업식 표현)
- "활용하다" ("쓰다"로 충분함)
- "패러다임 전환" (불분명함)

## 예시

### ✅ 좋은 예시
"Claude가 코드 리뷰 과정을 자동화합니다. PR마다 직접 확인하는 대신 Claude가 보안, 성능, 품질을 리뷰해 팀의 시간을 매주 몇 시간씩 아껴 줍니다."

효과적인 이유: 가치가 분명하고, 이점이 구체적이며, 행동 중심적입니다

### ❌ 나쁜 예시
"Claude는 최첨단 AI를 레버리지하여 종합적인 소프트웨어 개발 솔루션을 제공합니다."

효과가 없는 이유: 막연하고, 기업식 전문 용어이며, 구체적인 가치가 없습니다
